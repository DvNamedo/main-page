## 1. 답변 기록과 판정 기준

- `Q28`은 `CF-LIBRARY-28`과 대응한다. 기존 하위 번호의 재질문 제외·통합은 §3에 보존했고, 이번 답변은 §2에 연결했다. 번호를 다른 의미로 재사용하지 않는다.
- **사용자 답변**과 **앞선 답변에서 도출한 해석**, **개발자 선택**을 구분한다. 후자의 두 종류는 `AUTO-Q…` 표식으로 기록하며 추후 교정할 수 있다.
- 저장 검증·중복 효과 방지·거짓 성공 방지·권한 검사는 개발자의 책임이다. 이를 할지 말지 묻지 않는다. 실제 운영의 자료 보관·허용/금지·담당자 접근 방식은 §2/4의 사용자 답변을 적용한다.
- ‘제재’는 연체 반납 뒤 신규 대출을 제한하는 패널티, ‘동결’은 대출 기한 진행 정지다. ‘대출 DB’는 동아리 스프레드시트의 항목이다.
- Q21·Q43·Q44는 현재 답변할 필요가 없다. 실제 기술 제약이 확인되면 구체적인 결과와 가능한 대안을 제시한 뒤에만 묻는다.
- 일부 답만 받았거나, 자체 선택이 다른 미확정 규칙에 의존하면 그 의존 부분은 계속 미정이다. 이 문서에서 질문을 제외했다는 이유로 구현·실현 가능성까지 통과시키지 않는다.

## 6. 기술 확인 뒤에만 묻는 조건부 3개 묶음

### Q21. 직접 수정이 다음 재조회에 반영되지 않는 제약이 실제로 확인되면 어떤 대안을 택할까요?

근거: [CF-LIBRARY-21](library-management-confirmation-required.md#cf21). 선행: TV01.

다음 재조회 반영 목표는 유지한다. 개발자가 충족하지 못하는 지연의 실제 원인·측정 결과·가능한 대안을 제시한 뒤에만 다음을 묻는다.

- **Q21-1:** 확인된 지연을 허용할까요, 기존 목표를 만족하는 다른 구현을 택할까요?
- **Q21-2:** 지연을 허용한다면 어느 정도까지이며 어떤 수동 확인 절차를 수용할까요?

현재 지연을 실측하지 않았으므로 숫자나 구성을 미리 선택하지 않는다.

### Q43. 브라우저/홈 화면 사이 기존 대출 연결이 끊기는 환경이 확인되면 어떻게 안내할까요?

근거: [CF-LIBRARY-43](library-management-confirmation-required.md#cf43). 선행: TV05.

단절 환경과 재현 조건이 실제 확인된 경우에만, 기존 대출 브라우저를 계속 사용하고 이메일로 대체할지, 첫 대출 전에 지정 문맥에 들어오게 안내할지 선택받는다. 현재 단절을 관찰한 것은 아니며 학번/이메일 병합·쿠키 복구도 추가하지 않는다.

### Q44. 무료 운영이나 필수 지원을 기존 조건으로 충족하지 못하면 어떤 구체 대안을 받아들일까요?

근거: [CF-LIBRARY-44](library-management-confirmation-required.md#cf44). 선행: 관련 TV01~07.

기존 조건을 충족하지 못한 사실과 실제 가능한 대안을 개발자가 제시한 뒤에만 비용·지원 범위·운영 절차·기준 저장소 변경을 선택받는다. 기존 조건을 유지하고 해당 구현/배포를 보류할 수도 있다. 무결성 위반을 수용하라는 선택지는 없다. 현재 다른 구성·유료 서비스가 필요하다는 결과는 없다.

## 7. 적용 방법·문서 검토·추적 상태

- P02: 이번 소유 변경은 기존 질문 문서의 답변·상태·출처 갱신이다. 권한·자료 수명의 의미는 관련 분석 모델에 연결하고, 이 문서에서 계정/DB/업무 코드나 새 외부 연동을 구현하지 않는다. 별도 UI·DFD·설계 그림은 답변 기록의 목적에 필요하지 않아 생략했다.
- P06: 최신 답과 이전 질문의 대상·조건을 대조했다. 사진만 삭제/사진 교체/DB 포함 삭제, 회원/관리자 시간 제한, 계정 수명/인증 상태를 구별했다.
- P07/M10: Q32의 짧은 응답 범위 보완은 AUTO-Q32-ANSWER로 표시했다. §5는 자율 분석에서 가정으로 다룰 대상으로 이관하며 사용자 원문·개발자 선택·가정을 섞지 않는다. 기존 질문의 번호와 과거 제외 분류는 보존했다.
- 변경 범위: 이 질문 문서의 최신 답변·현재 상태·추적 기록만 갱신. 업무 코드/계정/실제 자료·네트워크 변경 및 테스트 실행 없음.
