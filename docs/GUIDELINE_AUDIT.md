# 개발 지침 전체 감사와 방법론 채택 기록

## 수행 순서

사용자 요청에 따라 다음 순서를 고정했다.

1. 기존 지침 전체를 읽고, 수행·선택·판정 방식이 열려 있는 표현을 식별해 목록으로 정리한다. 방법이 여러 개 가능한데 후보와 선택 조건이 없는 경우도 포함한다.
2. 확정한 목록의 각 항목에 대해 제공 PDF 또는 공식·저자 자료에서 구체적 방법론을 조사한다. 적용 가능한 후보, 기본 선택, 다른 방법의 선택 조건, 수행 절차, 산출물, 판정 기준을 정리한다.
3. 원문 지침·세부 기준·양식에 연결하고 목록과 대조해 누락·충돌·근거 없는 채택이 있는지 확인한다.
